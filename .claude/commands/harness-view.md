# /harness-view - 하네스 세팅 화면

이 프로젝트에 하네스가 어떻게 세팅돼 있는지 HTML 한 장으로 그려 브라우저로 연다. 보기 전용이다.

```bash
python3 .claude/scripts/harness_view.py --open
```

스크립트가 설치된 파일만 읽어 그린다 (`.claude/project.json`, 어댑터, 에이전트 도구, 세팅 설명서, 보충 칸, 도메인 문서, 설치 기록).
LLM 이 내용을 요약하거나 고쳐 쓰지 않는다. 화면의 값은 파일과 같아야 한다.
결과 파일은 `.claude/state/harness-view.html` 이고 커밋하지 않는다. 파일 밖으로 아무것도 보내지 않는다.

실행 뒤 사용자에게 알릴 것:
1. 스크립트가 출력한 경로와 요약 한 줄 (채운 칸 수, 도메인 문서 수, 업데이트 알림이 있으면 그것)
2. 브라우저가 안 열리는 환경이면 그 경로를 직접 열라고 안내한다

화면에서 무엇을 바꾸고 싶다고 하면 직접 고치지 않고 `/setup` 으로 안내한다.
"비운 것만 채우기" 나 특정 에이전트만 다시 하기를 고르면 된다.
