# discuss 보충 (2026-09-30, /setup)

## 피할 곳
- 오프라인, 로그인과 권한, 결제 축은 묻지 않는다. 뷰어는 로컬 도구이고 라이브러리는 앱에 심는 로거다
- 뷰어에 외부 의존성을 들여야 하는 제안은 하지 않는다 (표준 라이브러리만, DECISIONS D13)

## 우선순위와 당부
- 외부 시스템은 `adb logcat`(기기), 로그 파일, 브라우저뿐이다. 서버, API, 큐는 없다
- 같은 상태를 여러 곳이 본다: 뷰어 하나에 브라우저 탭 여러 개가 SSE 로 붙는다. 원본은 로컬 뷰어 프로세스다
- 새 기능마다 이 넷은 꼭 묻는다
  - 규칙을 안 지킨 로그(레거시 태그, 잘린 줄, raw 강등)에서는 어떻게 보이나
  - 근사치나 부분 관측인데 정확한 값처럼 보이지 않나 (D11, D23-⑤)
  - 로그 본문의 개인정보가 산출물(config, 스냅샷 파일)로 새지 않나 (D18)
  - 기기 없이 `--source synth` 로 개발하고 시연할 수 있나 (D14)
